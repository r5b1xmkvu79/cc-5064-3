# 大纵深场景深度精度试验器

同一组近/远薄板，在**常规**与**反向**深度表示、**UNORM24** 与 **FLOAT32** 缓冲、
**有限/无限远平面**之间比较深度精度。所有结论由一个与渲染解耦的纯 JS 内核计算，
WebGL2 光栅视窗负责真实的遮挡、拾取和缓冲读回，二者用同一套投影/重建公式并互相校验。

## 怎样启动界面

```bash
npm run serve          # 零依赖静态服务器
# 打开 http://localhost:8080
```

浏览器要求支持 WebGL2 与 `EXT_color_buffer_float`（桌面 Chrome/Firefox/Edge 与近年
移动端普遍支持）。页面顶部胶囊会显示实际能力；不支持浮点颜色附件时 FLOAT32 FBO
会被标记为 incomplete 并从格式下拉中移除。

无头环境下用内核与扫描验证，不依赖浏览器：

```bash
npm test               # 20 个 node:test 用例（投影、量化、重建、区块、扫描）
npm run stub           # WebGL2 桩：FBO/MRT/uniform/读回接线检查（无 GPU，不验证真实光栅化）
npm run sweep          # 相机范围 × 格式 × 约定 × 远平面 的失效距离扫描
npm run workflow       # 拾取→推近局部刷新→裁面跳变 的端到端内核模拟
```

真实光栅化、遮挡与误差图必须在浏览器中确认；本环境无 GPU，已通过 WebGL2 桩拦截
着色器/uniform/附件接线错误，但像素级结果需 `npm run serve` 后人工或浏览器自动化核对。

## 界面操作流（对应需求中的制图员流程）

1. 启动后两个视窗以同一场景渲染路径 A / 路径 B，默认 A=UNORM24 常规、B=FLOAT32 反向。
2. 在远景 **FAR-A / FAR-B** 两层薄板上点击点选；结果区显示精确视距、内核投影 z、
   硬件缓冲 z（R32F MRT 读回的 `gl_FragCoord.z`）、由深度重建的距离与重建误差。
3. 点 **推近相机（局部刷新）**：只对视口中心区块做 scissor 刷新，其余区块保留历史样本，
   区块状态图显示 新鲜/重映射/未决/抢占/空。
4. 调整 near/far 或点 **裁面跳变**：旧深度与新深度落入不同区间。保存视空间距离的区块
   精确重映射；仅存量化码且两个候选的新码格相交时标为**未决**（需重绘），同码则标**抢占**。
5. 显示模式切换 **着色 / 误差图 / 原始深度**。误差图在片元着色器里用与内核相同的公式
   从硬件深度重建距离，再与 MRT 写出的精确视距对比，按相对误差上热力色。
6. 移动“远景/近景薄板距离”和 gap 滑杆观察遮挡抢占；薄板物理厚度固定，不通过偏移模型
   消除冲突。精度曲线图中的 gap 红线与曲线的交点即可分辨间距的失效范围。

## 深度约定（不是只把比较符号反过来）

| 组合 | 清除值 | 比较函数 | near→z | far→z | 适用条件 |
|---|---|---|---|---|---|
| UNORM24 常规有限 | 1 | LEQUAL | 0 | 1 | 小纵深、near/far 比 < ~10³ |
| UNORM24 反向有限 | 0 | GEQUAL | 1 | 0 | 与常规 UNORM24 精度相同，仅改比较方向 |
| FLOAT32 常规 | 1/∞ | LEQUAL | 0 | 1/→1 | 浮点在 z≈1（远端）ulp 最大，远端仍差 |
| **FLOAT32 反向 无限远** | **0** | **GEQUAL** | **1** | **→0** | **大纵深推荐：近物落在高精度的 z≈1，远物落在 ulp 最小的 z≈0** |

关键事实（`npm run sweep` 可复现）：

- 反向 + UNORM24 **不会**提升精度，码格跨度与常规 UNORM24 相同；收益只来自
  “反向 + 浮点 + 无限远平面”三者组合，把透视双曲线的高代价区对准浮点高精度区。
- 透视下常规 UNORM24 的距离步进 Δd ∝ d²，远端一个码格可跨数米。
- 失效距离 `failureDistance(params, format, gap)` 给出两个相距 gap 的表面仍能获得
  不同深度码的最大距离；超过即 z-fight。

## 目录结构

```
src/depth-kernel.js  纯数学内核：投影、UNORM24/FLOAT32 量化、重建、码格区间、
                     区块重映射(remapBlock)、失效距离、范围扫描、组合推荐
src/mat4.js          透视(有限/无限)、lookAt、轨道相机
src/geometry.js      近/远薄板对（固定物理厚度）、地面网格、稳定对象 id
src/renderer.js      WebGL2：双 FBO、MRT(color + 硬件深度R32F + 精确视距R32F)、
                     LEQUAL/GEQUAL 与清除值、scissor 局部刷新、readPixels 读回、误差图后处理
src/block-store.js   区块存储（距离/仅码两种模式）与裁面变更后的换算状态机
src/charts.js        精度分布曲线(Δd-d 对数图)与区块状态图
src/app.js           控件、拾取、遮挡次序校验、扫描表、事件日志
test/                node:test：内核、投影矩阵与 GLSL 重建公式一致性、区块状态机
tools/sweep.js       命令行扫描；tools/serve.js 静态服务器
```

## 验证了什么

- 投影矩阵产生的窗口深度与内核解析公式一致（含反向/无限远，容差 1e-8）。
- 着色器里的重建公式与内核 `reconstructDistance` 一致。
- 距离模式区块在裁面变化后精确重映射并保持正确的近面获胜者；仅码模式在同码格时
  进入未决，码格不相交时给出确定性获胜者。
- FLOAT32 反无限远能分辨 UNORM24 已塌缩的远端间距。
- 读回的硬件深度与内核量化期望逐像素比对；遮挡次序用已知板号（A 物理上更近）核对。
